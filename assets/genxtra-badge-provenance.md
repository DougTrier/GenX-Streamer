# GenXtra badge

`genxtra-badge.png` (1351×545) comes from the user's ChatGPT-generated `I:\GenX Sprites\Neon GenXtra Synthwave Badge.png`, supplied on October 18, 2026. That file was not truly transparent: a dim haze surrounded the badge. With Pillow, faint near-black pixels were made fully transparent and the image was cropped to the badge (box 49,259 to 1400,804). The artwork itself is unchanged.

`genxtra-badge-display.png` (317×128) is the same artwork downscaled with Pillow's Lanczos filter on premultiplied alpha. The top bar shows the badge at about 30 CSS pixels tall, so the display copy covers 4× screens while decoding to about 160 KiB. The full-size source is kept unchanged.

The badge replaces the GenXtra button's visible text; the button keeps "GenXtra" as its accessible name, and if the image fails to load the text label returns.
