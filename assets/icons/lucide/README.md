# Lucide icons

These SVG files are unmodified copies from the npm package `lucide-static@1.51.0`
(tarball SHA-256 `6936026d1512256483161ae999982e3be3d5d74226996c4ec7447e901726a2d8`),
taken on October 18, 2026. Each file keeps its `@license lucide-static v1.51.0 - ISC` header;
`LICENSE` is the package's licence text (ISC, with the MIT notice for icons derived from Feather).

The app uses them only as CSS masks painted in the button's own text colour, so they stay crisp at
every size and follow the button's normal, selected and focused colours. Only the icons the app
shows are copied; nothing is fetched at run time.
