Install and set up GenX Streamer

GenX Streamer is a free, open-source live TV app for Windows and Android TV, phones and handhelds. This guide takes you from the official download to watching your first channel.

Install on Windows 10 or Windows 11

You need 64-bit Windows 10 or 11 and Microsoft Edge WebView2 Runtime, which is built into Windows 11.

  1. Open the Windows download page and download the portable ZIP.
  2. Extract the whole ZIP into its own folder. Keep its files together.
  3. Open GenX Streamer.exe from that folder.

Before opening a download, you can compare its SHA-256 checksum with the official release. See how to verify your copy.

Install on an Android phone, tablet or handheld

You need Android 7.0 or newer on a 32- or 64-bit ARM device. The APK is not for x86 Android devices. There is currently no iPhone, iPad or Mac version.

  1. Open the Android download page on your device and download the APK.
  2. Open the downloaded APK. If Android asks, allow installation for the browser or file manager you used to open this official file.
  3. Confirm installation, then open GenX Streamer.

Install on Android TV or Google TV from your phone

  1. Install GenX Streamer on your Android phone and connect the phone and TV to the same Wi-Fi.
  2. In GenX Streamer on the phone, open Settings → Send app to a friend → Install on TV.
  3. Select your TV, enter the code it shows and approve the steps on the TV using its remote.
  4. If the TV needs a download helper, follow the prompts to install it first. Wait for Ready! GenX Streamer is installed. on the phone.

See the full phone-to-TV instructions and unedited installation demo.

Start watching and add a program guide

Use Free TV to find public live channels, or bring your own playlist. For your own source, open Settings → Add channels, enter its URL or select a playlist file, then review and save the channels. Paid TV needs your own provider account; GenX Streamer does not include a paid subscription.

Choose a channel to watch. Use Favorites and search to find it again. With a TV remote, use the directional keys to move and OK to select.

For your own XMLTV program listings, open Guide → Guide sources, add your URL or file, review and save the preview, then check the channel mapping. Listings depend on the guide source.

Help with installation and playback

A channel will not play

Try another channel and check your internet connection. Public streams can move, go offline or be restricted by location. A saved channel or program listing does not guarantee playback.

The download page cannot find a release

Try again when online, or open the official GitHub release page for the files and checksums.

An Android update will not install

A development build and an official release can use different signing identities. Back up your library before replacing a development copy. See the migration instructions before uninstalling or clearing data.

Read the full user guide, or check GitHub issues for known problems and bug reports.
